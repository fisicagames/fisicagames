# 👋 Hi, I'm Rafael

Physics teacher and developer. I create interactive 3D physics simulations
designed to run directly in mobile browsers — without installation, login,
or paywalls — so that physics content reaches people in their everyday
digital spaces.

🔭 **Current focus**

- Hypercasual physics simulations: simple, mobile-first, instant access
- Custom MVC framework in TypeScript with Babylon.js for rapid simulation development
- Exploring AI-assisted code generation for physics modules

🛠 **Tech stack**

TypeScript · Babylon.js · Havok Physics · Vite · Blender · Git

🎓 **Background**

Ph.D. in Science and Technology Education. I teach physics at the
Federal Institute of Paraná (IFPR), with research focused on interactive
simulations for physics education and public engagement with science.

🌐 **Portal**

All simulations are free to play at [www.fisicagames.com.br](https://www.fisicagames.com.br)
